MON CONGÉLATEUR — VERSION INSTALLABLE SUR IPHONE

CONTENU
- index.html : application
- manifest.json : métadonnées d'installation
- service-worker.js : cache hors ligne
- icon-192.png et icon-512.png : icônes

IMPORTANT
Ce dossier est préparé comme une PWA, mais un iPhone ne peut pas l'installer depuis un fichier local.
Il faut d'abord publier ces fichiers sur un hébergement HTTPS. Aucun hébergement n'a été créé depuis ce paquet.

INSTALLATION SUR IPHONE APRÈS PUBLICATION HTTPS
1. Ouvrir l'adresse HTTPS du site dans Safari sur l'iPhone.
2. Appuyer sur Partager.
3. Choisir « Sur l'écran d'accueil ».
4. Activer « Ouvrir comme app » si l'option apparaît, puis toucher Ajouter.

DONNÉES ET NOTIFICATIONS
- Le stock est enregistré dans le stockage local du navigateur/appareil. Exportez régulièrement une sauvegarde depuis Outils.
- Le cache permet de rouvrir l'interface hors ligne après le premier chargement.
- Nouvelle fonction : l’onglet Alertes affiche les aliments dont la date de congélation remonte à un an ou plus, dès que tu ouvres l’application.
- Les notifications automatiques en arrière-plan ne sont pas implémentées comme des rappels fiables dans ce prototype. Les alertes d’un an s’affichent dans l’application à son ouverture.
- Les données locales ne se synchronisent pas entre appareils.
